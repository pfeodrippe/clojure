## Migration Mechanics: How to Wire It Up

### Pattern 1: Direct Replacement (for pure functions)

**Java (before):**
```java
static public String munge(String name){
    StringBuilder sb = new StringBuilder();
    for(char c : name.toCharArray()) {
        String sub = (String) CHAR_MAP.valAt(c);
        if(sub != null)
            sb.append(sub);
        else
            sb.append(c);
    }
    return sb.toString();
}
```

**Java (after):**
```java
static public String munge(String name){
    try {
        Var mungeVar = Var.find(Symbol.create("clojure.compiler.java-interop", "munge-symbol"));
        if (mungeVar != null && mungeVar.isBound()) {
            Object result = ((IFn)mungeVar.deref()).invoke(name);
            if (result instanceof String) {
                return (String) result;
            }
        }
    } catch (Exception e) {
        // Fall back to Java implementation if Clojure not loaded
    }
    
    // Original Java implementation as fallback
    StringBuilder sb = new StringBuilder();
    for(char c : name.toCharArray()) {
        String sub = (String) CHAR_MAP.valAt(c);
        if(sub != null)
            sb.append(sub);
        else
            sb.append(c);
    }
    return sb.toString();
}
```

**Benefits:**
- ✅ Zero risk: Falls back to Java if Clojure fails
- ✅ Progressive: Can enable/disable via flag
- ✅ Testable: Same test suite works

**Java (before):**

### Pattern 3: Incremental Bytecode Replacement

**Strategy:**
1. Add flag: `USE_CLOJURE_BYTECODE_GEN` (default: false)
2. In `FnExpr.compile()`, check flag:
   ```java
   if (USE_CLOJURE_BYTECODE_GEN) {
       return compileViaClojure(superName, interfaceNames, oneTimeUse);
   } else {
       // Existing Java bytecode generation
   }
   ```
3. Implement `compileViaClojure()`:
   ```java
   private void compileViaClojure(String superName, String[] interfaceNames, boolean oneTimeUse) {
       Var compileVar = Var.find(Symbol.create("clojure.compiler.phase6", "compile-fn-class"));
       if (compileVar != null) {
           // Pass this FnExpr's data to Clojure
           // Let phase6.clj generate bytecode
           // Return compiled class
       }
   }
   ```

## Risk Mitigation

### Risk 1: Performance Regression
**Mitigation:**
- Benchmark every migration
- Keep Java fallback always available
- Profile hot paths
- Accept <2% overhead (worth it for maintainability!)

### Risk 2: Test Failures
**Mitigation:**
- Run full test suite after EVERY change
- Fix immediately or revert
- Never merge broken code
- Keep bootstrap system robust

### Risk 3: Subtle Behavioral Changes
**Mitigation:**
- Compare outputs: Java vs Clojure
- Extensive edge case testing
- Property-based testing where applicable
- Community testing (real-world codebases)

### Risk 4: Complexity
**Mitigation:**
- One function at a time
- Document every migration
- Incremental approach (Tier 1 → 2 → 3)
- Celebrate small wins! 🎉
