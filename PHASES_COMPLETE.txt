## 🚀 How to Use

### Quick Start
```bash
# Compile
mvn compile

# Run all phases
./run_all_phases.sh

# Or run individually:
mvn exec:exec -Dexec.args="-cp %classpath clojure.main demo_phase2.clj"
mvn exec:exec -Dexec.args="-cp %classpath clojure.main demo_phase3.clj"

# Tests
mvn -Ptest-direct test
```

### REPL Usage
```clojure
;; Phase 1: Java Interop
(require '[clojure.compiler.java-interop :as ji])
(ji/munge-name "hello-world")  ; => "hello_world"

;; Phase 2: Compiler Utilities  
(require '[clojure.compiler.phase2 :as p2])
(p2/try-fold '+ [1 2 3])      ; => 6
(p2/infer-tag [1 2 3])        ; => IPersistentVector

;; Phase 3: AST Analysis
(require '[clojure.compiler.phase3 :as p3])
(p3/analyze-scope '(fn [x] (+ x y)))
;; => {:bound #{x}, :free #{y +}}
```
